# RateMyProfessor Machine Learning Analysis

A statistical and machine learning project analyzing RateMyProfessor
data to study professor ratings and build predictive models.

## Project Overview

This project applies statistical testing and machine learning to examine
relationships between professor ratings, difficulty, number of ratings,
online ratings, and other characteristics.

## Methods

### Statistical Analysis
- Mann-Whitney U Test
- Permutation Testing
- Spearman Correlation

### Machine Learning
- Linear Regression
- Lasso Regression with 5-fold cross-validation
- Logistic Regression
- Train-test validation

## Model Evaluation

Regression models were evaluated using:
- R²
- RMSE

Classification models were evaluated using:
- ROC-AUC
- Accuracy
- Precision
- Sensitivity / Recall
- Specificity
- Confusion Matrix

## Tools

Python | Pandas | NumPy | SciPy | Scikit-learn | Matplotlib | Seaborn

## Key Takeaway

The project emphasized not only fitting predictive models, but also
evaluating whether their outputs generalized to held-out data using
train-test splits, cross-validation, and multiple performance metrics.
